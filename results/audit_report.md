## 8. Cleaning decisions and justification

1. **Placeholders ('ЖОҚ', 'undefined', '', '-', ...) -> NA** - They are source-system fill values, not information; counting them as values would inflate cardinality and create fake classes.

2. **`database_section` numeric codes ('3700', '3800') -> NA** - Not section names (19 rows); cannot be mapped to a curated area, so treated as missing for task `area`.

3. **`is_archive` dropped from modelling** - Constant column ('f' for every row) - zero information.

4. **`act_form` parsed as an unordered tag set (strip whitespace, split on ',')** - Raw strings differ only by tag order/padding; set semantics collapses order-only duplicates.

5. **`legal_relation_area` split with a parenthesis- and case-aware splitter** - Naive ', ' splitting breaks names that contain commas; numeric classifier codes are dropped.

6. **Primary form = highest base form in Заң > Жарлық > Қаулы > Шешім > Бұйрық > Өкім, else Басқа; missing act_form -> unlabelled (row excluded from task `form`)** - Joint acts carry several base forms; a hierarchy gives one deterministic label (aliases such as 'Нормативтік қаулы' -> Қаулы). A missing form is unknown, not 'other', so it must not become a training label.

7. **Titles normalised for duplicate detection: NFC, lower-case, Latin->Cyrillic homoglyph folding, punctuation removed** - ~11 % of titles write Kazakh 'і' as Latin 'i'; without folding, copies of the same title escape the leakage guard.

8. **Rare areas (< 300 train rows) collapsed to Басқа, decided on TRAIN only** - Classes with a handful of examples make macro-F1 unstable; using train counts only avoids peeking at test.

9. **Temporal split train <= 2021, val 2022, test >= 2023** - Mimics deployment on future acts and prevents look-ahead leakage.

10. **Val/test rows whose normalised title occurs in train removed; test_strict also excludes titles identical up to digits and near-duplicates (char-gram cosine >= 0.9 on digit-masked titles)** - Templated titles repeat every year with new dates/numbers; without this the test set measures memorisation.

11. **Titles kept verbatim for models (no truncation at data level, NFC-normalised in text_prep)** - Length outliers are genuine (long amendment titles); models truncate at their own max length.

12. **Dates parsed with strict ISO format; anomalies reported, not 'fixed'** - No ground truth to repair them; affected rows are few and dates only drive the split by year.
